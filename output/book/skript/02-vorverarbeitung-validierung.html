2  2 Preprocessing & Validation of a Time Series

3 2 Preprocessing & Validation of a Time Series

Before a time series is analyzed, it must be formally correct and consistent.

Many errors in later analyses arise from:

  • unsorted timestamps
  • duplicate timestamps
  • missing values
  • irregular sampling
  • implicit time gaps
NoteRemember

Time series analysis is only as good as the underlying data. Validation is not an optional step.

3.1 2.1 Example Time Series with Problems

We intentionally create a faulty time series (unsorted, duplicates, missing values).

import numpy as np
import pandas as pd

rng = np.random.default_rng(1)

t = pd.date_range("2025-01-01", periods=24*3, freq="h")
y = pd.Series(10 + rng.normal(size=len(t)), index=t, name="signal")

# create problems
y = y.sample(frac=1)                      # unsorted
y = pd.concat([y, y.iloc[5:8]])           # duplicates (append is deprecated/removed)
y.iloc[10:15] = np.nan                    # missing values

y.head()

3.3 2.3 Step 2: Detecting and Handling Duplicates

Detect duplicates:

dup_mask = y.index.duplicated(keep=False)
y[dup_mask].head(10)
2025-01-01 21:00:00     9.724397
2025-01-01 21:00:00     9.724397
2025-01-02 13:00:00     8.351925
2025-01-02 13:00:00     8.351925
2025-01-03 18:00:00    10.235506
2025-01-03 18:00:00    10.235506
Name: signal, dtype: float64

Duplicates must be handled methodically, for example:

  • Average per timestamp (typical for measurements)
  • Keep first/last value (typical for status updates)
  • Remove (if clearly erroneous)

Example: Average per timestamp

y = y.groupby(level=0).mean()

3.4 2.4 Step 3: Analyze Missing Values

y.isna().sum()

3.4.1 Visualizing the Gaps

import matplotlib.pyplot as plt

y.plot(title="Time Series with Missing Values")
plt.show()

3.4.2 Treatment options

y_ffill = y.ffill()
y_interp = y.interpolate("time")
TipDecision Helper
  • ffill: useful for state data (“applies until the next measurement”)
  • interpolate("time"): useful for continuous measurements

3.5 2.5 Step 4: Check Sampling Rate

Is the time series regular?

diffs = y.index.to_series().diff()
diffs.value_counts().head()
0 days 01:00:00    71
Name: count, dtype: int64

If multiple time intervals occur → irregular sampling or time gaps.

3.6 2.6 Making Time Gaps Explicit

Using asfreq enforces the expected frequency. Missing time points appear as NaN.

y_regular = y.asfreq("h")
y_regular.isna().sum()
5
WarningWarning

Without an explicit frequency, gaps in time may remain invisible.
