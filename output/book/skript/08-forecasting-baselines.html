9 8 Forecasting Baselines & Evaluation

Before applying complex models, simple baseline models should always be defined.

Baselines answer the question:

Is my model truly better than a simple, understandable strategy?

Note

A complex model only makes sense if it clearly outperforms robust baselines.

9.1 8.1 Example Time Series

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

rng = np.random.default_rng(123)

t = pd.date_range("2025-01-01", periods=24*14, freq="H")
trend = np.linspace(0, 2, len(t))
season = 0.9 * np.sin(2*np.pi*(t.hour)/24)
noise = 0.3 * rng.normal(size=len(t))

s = pd.Series(20 + trend + season + noise, index=t, name="signal")

s.plot(title="Time Series for Forecasting")
plt.show()

We use 80% of the data for training and 20% for testing.

9.3 8.3 Naive Forecast

Next value = last observed value.

  • Pandas
  • NumPy
naive = test.copy()
naive[:] = train.iloc[-1]
y = s.to_numpy()
train_np = y[:split]
test_np = y[split:]

naive_np = np.full_like(test_np, train_np[-1])

9.4 8.4 Seasonal Naive (24 Hours)

Next value = value from 24 hours ago.

  • Pandas
  • NumPy
seasonal_naive = s.shift(24).iloc[split:]
seasonal_naive_np = y[split-24:-24]

9.5 8.5 Moving Average Baseline

Forecast = mean of the last 24 hours.

  • Pandas
  • NumPy
ma_value = train.iloc[-24:].mean()
ma_forecast = test.copy()
ma_forecast[:] = ma_value
ma_value_np = np.mean(train_np[-24:])
ma_forecast_np = np.full_like(test_np, ma_value_np)

9.6 8.6 Visualizing Comparison

plt.figure()
train.plot(label="Train")
test.plot(label="Test")
naive.plot(label="Naive")
seasonal_naive.plot(label="Seasonal Naive")
ma_forecast.plot(label="MA(24)")
plt.legend()
plt.title("Forecast Baselines")
plt.show()

9.7 8.7 Error Metrics

We use the Mean Absolute Error (MAE):

[ MAE = |y_{true} - y_{pred}| ]

  • Pandas
  • NumPy
def mae(y_true, y_pred):
    return np.mean(np.abs(y_true - y_pred))

print("MAE Naive:", mae(test, naive))
print("MAE Seasonal Naive:", mae(test, seasonal_naive))
print("MAE MA(24):", mae(test, ma_forecast))

9.8 8.8 Interpretation

Typical observations:

  • With a strong seasonal pattern, Seasonal Naive often performs best.
  • With a weak pattern, Naive can be surprisingly strong.
  • Moving Average smooths the data but reacts slowly to trend changes.
Methodological Note

Comparing to a baseline is not a formality, but a quality check.
